# No Python here any more. Cards are built by the `anki-cards` skill
# (.claude/skills/anki-cards/SKILL.md), which reads your source files and writes
# notes through the Anki MCP server. There is no driver to install or run.
#
# WHAT YOU ACTUALLY NEED
#
#   Anki, running, with the AnkiConnect add-on (code 2055492159).
#   The `anki` MCP server connected — that is how notes get written.
#
# TURNING SOURCE FILES INTO TEXT (before asking for cards)
#
#   poppler      pdftoppm, pdftotext  — render slides to images, pull slide text
#                `brew install poppler`
#   libreoffice  soffice  — convert .ppt/.pptx to PDF first
#                `brew install --cask libreoffice`
#   textutil     built into macOS — .doc/.docx/.rtf to text
#
# TRANSCRIBING A LECTURE RECORDING
#
#   ffmpeg       `brew install ffmpeg`
#   mlx-whisper  `uv tool install --python 3.13 mlx-whisper`
#
#   Long lectures REQUIRE --condition-on-previous-text False, or large-v3 silently
#   loops a phrase for minutes and still exits 0. Always check the output:
#     sort transcript.txt | uniq -c | sort -rn | head
